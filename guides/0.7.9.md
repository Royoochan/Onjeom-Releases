# 온점 0.7.9 친구 테스트 안내

Windows 10/11 64비트에서 사용합니다. Edge 또는 Chrome이 필요합니다.

1. Onjeom_Setup_0.7.9.exe를 실행해 설치하세요. 관리자 권한은 필요하지 않습니다.
2. 바탕화면 또는 시작 메뉴의 온점을 실행하고 이름을 입력하세요.
3. 친구방을 만들고 6자리 초대 코드를 친구에게 보내세요.
4. 친구는 온점을 설치한 뒤 같은 코드를 입력해 참가합니다. 입장 승인 옵션이 켜져 있으면 방장이 친구방 화면에서 승인하세요.

대국 2명과 관전 3명이 한 방에 들어갈 수 있습니다. 서로 다른 인터넷에서도 함께 둘 수 있습니다.
무료 서버가 쉬고 있으면 첫 연결에 약 1분 걸릴 수 있습니다. 혼자 연습은 인터넷 없이 바로 됩니다.
혼자 연습은 흑백을 직접 번갈아 두는 방식입니다.

설치본은 새 버전을 자동 확인합니다. 준비된 업데이트는 다음 실행 때 적용하며 대국 중 강제 재시작하지 않습니다.
재접속할 때는 같은 PC와 앱을 이용하세요. 계정 로그인이나 다른 PC로 자리 옮기기는 아직 지원하지 않습니다.

삭제: Windows 설정 → 앱 → 온점 (ONJEOM) → 제거.
제어판 → 프로그램 및 기능에서도 제거할 수 있습니다. 연습 기록과 설정은 보존됩니다.

Windows 코드 서명 인증서는 아직 적용하지 않아 게시자 확인 안내가 나올 수 있습니다.
공식 배포처에서 받은 설치 파일인지 확인하세요.
공식 배포: https://github.com/Royoochan/Onjeom-Releases/releases/tag/v0.7.9
설치 안내 페이지: https://minibaduk-dev.onrender.com/download

오류를 알려주실 때는 화면 아래 버전, 어떤 버튼을 눌렀는지, 예상과 실제 동작, 화면 사진을 함께 남겨 주세요.
비밀번호·초대 코드·개인 정보는 올리지 마세요.

재접속 정보는 Windows 사용자 보호 저장소에 보관합니다. 친구방에서 본인 정보 삭제를 요청할 수 있으며, 진행 중 삭제는 기권으로 처리됩니다. 공동 기록은 익명화해 원래 보관 기한을 따릅니다. 완료 기보 24시간, 미활동 방 48시간, 방 최대 7일입니다.
