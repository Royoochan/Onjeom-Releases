# 온점 · ONJEOM

작은 크림색 창에서 친구와 한 수씩 즐기는 무료 Windows 바둑 앱입니다.

**[온점 0.7.11 친구 베타 설치 파일 받기](https://github.com/Royoochan/Onjeom-Releases/releases/download/v0.7.11/Onjeom_Setup_0.7.11.exe)**

Windows 10(버전 2004 이상)/11 64비트 · Edge 또는 Chrome 필요 · GitHub 로그인 없이 다운로드 가능

기존 설치자도 실행 중인 온점을 닫고 위 파일로 덮어 설치해 주세요. 기록과 설정은 유지됩니다.
**이번 친구 베타는 설치 파일로 직접 업데이트합니다.**

설치 후 이름을 입력하고 친구방을 만든 뒤 6자리 초대 코드를 친구에게 보내세요.
대국 2명과 관전 3명까지 함께할 수 있습니다. 입장 승인이 켜져 있으면 방장이 친구방에서 승인해 주세요.
무료 서버의 첫 온라인 연결에는 약 1분 걸릴 수 있습니다. 혼자 연습은 인터넷 없이 가능합니다.

- [오류 제보](https://github.com/Royoochan/Onjeom-Releases/issues/new/choose)

0.7.11에는 앱 내부 개인정보 안내와 시작할 때 브라우저·주소 화면이 먼저 보이는 현상 개선이 포함됩니다.
무료이며 회원 가입·결제·광고·채팅 기능이 없습니다. Windows 설정의 앱 목록에서 제거할 수 있습니다.

현재 친구 초대 베타이며 정식 v1.0 출시는 테스트와 오류 수정을 거친 뒤 진행합니다.
이 저장소에는 배포 파일·사용 안내·배포 절차만 있으며 앱 소스 코드와 개인키는 포함하지 않습니다.
