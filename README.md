# 온점 · ONJEOM

작은 크림색 창에서 친구와 한 수씩 즐기는 Windows 바둑 앱입니다. 무료이며 결제 기능은 없습니다.

**[온점 0.7.9 설치 파일 받기](https://github.com/Royoochan/Onjeom-Releases/releases/download/v0.7.9/Onjeom_Setup_0.7.9.exe)**

Windows 10/11 64비트 · Edge 또는 Chrome 필요 · GitHub 로그인 없이 다운로드 가능

설치 후 이름을 입력하고 친구방을 만드세요. 6자리 초대 코드를 친구에게 보내면 됩니다.
대국 2명과 관전 3명까지 함께할 수 있습니다. 입장 승인이 켜져 있으면 방장이 친구방에서 승인해 주세요. 무료 서버의 첫 연결에는 약 1분 걸릴 수 있습니다.

- [설치와 친구 초대 안내](https://minibaduk-dev.onrender.com/download)
- [친구 테스트 사용 안내](FRIEND_GUIDE.md)
- [오류 제보](https://github.com/Royoochan/Onjeom-Releases/issues/new/choose)

현재 친구 초대 베타입니다. 정식 v1.0 출시는 테스트와 오류 수정을 거친 뒤 진행합니다.
이 저장소에는 배포 파일·사용 안내·배포 절차만 있으며, 앱 소스 코드와 개인키는 포함하지 않습니다.
설치본은 자동 업데이트를 지원하며 Windows 설정의 앱 목록에서 제거할 수 있습니다.
